---
title: 'Switching tabs'
prompt: 'Open the "Counter" tab, click "+1" three times, go back to "Home", then open "Counter" again. What does it show?'
---

## Expected output

It shows **Count: 3**.

## Why

Both tabs stay mounted, each in its own `<Activity>`. Switching tabs only flips which one is `"visible"`. The hidden `CounterTab` keeps its `count`, so it comes back at 3.

Switching tabs by rendering only the current one remounts it every time:

```tsx
{
  tab === 'counter' && <CounterTab />;
}
```

With that, going back to **Counter** shows **Count: 0**.

## Takeaway

Wrap each tab in `<Activity>` to switch between them without losing what the user did in each one.
